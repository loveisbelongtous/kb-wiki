# Obsidian

## 概述
本地 Markdown 笔记软件，作者在方案中用作「知识的家」。[?]（"知识的家"为作者主观表述）

## 核心信息
- **所属领域**：个人知识管理 / 本地笔记软件
- **主要特性**：文件本地存储（数据自持）、双向链接 + 知识图谱、Markdown 格式（利于 AI 读写）
- **关键组件**：Obsidian Web Clipper（浏览器插件，见 [[obsidian_web_clipper]]）
- **应用场景**：作为个人知识库的主存储与浏览端

## 详细内容
作者选择 Obsidian 的三点理由：① 文件本地存储，数据掌握在自己手里，不怕服务停运；② 双向链接 + 知识图谱，可直观看到概念之间的关联（见 [[双向链接]]、[[知识图谱]]）；③ Markdown 格式，AI 读写最自然。
